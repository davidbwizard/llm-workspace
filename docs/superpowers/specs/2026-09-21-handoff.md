## Things learned today that will save time later

- **There is no supported non-keystroke way to answer a Claude Code prompt.**
  Checked twice, independently. Hooks observe and can decide tool permissions;
  they cannot supply a selected option. The SDK's `canUseTool` is for its own
  runs. Remote Control has no programmatic surface. Screen-reading plus
  keystrokes is the ceiling, not a workaround -- do not go looking for an API
  before proposing a rewrite.
- **A container query cannot see a classic macOS scrollbar.** It measures the
  content box including the scrollbar gutter, so the same query width leaves
  15px less usable space in classic mode and the row wraps. The rail's
  breakpoints carry 15px of headroom for this; the fleet grid's do not, because
  a card is not a scroll container. There is a test pinning that difference.
- **macOS flips classic/overlay scrollbars system-wide when a mouse connects.**
  15px of width appears and disappears with no window resize. That is what made
  the rail bug intermittent and unreproducible.
- **Codex's composer submits on Enter even for an invalid command.** Text left
  in it that is not a real command goes to the model and spends quota. Clear
  the composer; never press Enter to clear it.
- **`claude doctor` and `codex doctor`** both exist, are free, and do not
  prompt. They are the right first-run probes.
- **Strings in a binary prove a word exists, nothing more.** The mode switcher
  spec's first Codex draft was built from binary strings and was wrong: Shift+Tab
  toggles Default/Plan only, and `/approvals` is not a command (`/permissions`
  is).
- **Do not check out a branch in the shared working directory while an agent is
  working there.** It silently moved an agent onto the wrong base. Give
  concurrent agents worktrees.
